# คู่มือคำสั่ง JudeCode

พิมพ์คำสั่งในช่องข้อความแล้วกด Enter ไม่จำเป็นต้องจำทั้งหมด:

- `/help` — ดูคำสั่งที่หน้าจอปัจจุบันรองรับ
- `/help all` — ดูคำสั่งทุกโหมด พร้อมระบุโหมดที่ใช้ได้
- `/help resume` หรือ `/help memory` — ค้นชื่อและคำอธิบาย
- `/commands` และ `/?` — ชื่ออื่นของ `/help`

## เริ่มใช้งาน

ใช้ `/model` ดูโมเดล, `/status` ดูสถานะ, `/budget` ดูประมาณการ token/ค่าใช้จ่าย, `/stop` ขอหยุด และ `/continue` ให้ทำงานต่อ

กู้บทสนทนาในหน้าจอหลักหรือ Legacy: `/sessions` → `/resume ID` (หรือ `/resume latest`) → ตรวจประวัติ → `/continue` การ resume ยังไม่รันเครื่องมือเอง ต้องอยู่ในโฟลเดอร์โปรเจคเดิม

## คำสั่งทั้งหมด

หน้าจอหลักเปิดด้วย `judecode`; ออกจากโปรแกรมก่อนเปลี่ยนเป็น `judecode --classic` หรือ `judecode --legacy` คำสั่งที่มีเฉพาะ Legacy ไม่สามารถใช้จากหน้าจอหลักได้

วงเล็บเหลี่ยมหมายถึงค่าที่เลือกใส่ได้ ส่วน ID/คำค้น/เป้าหมาย ให้แทนด้วยค่าที่ต้องการ


### เริ่มต้น

| คำสั่ง | ใช้ทำอะไร | โหมด |
|---|---|---|
| `/help` | ดูคำสั่งในโหมดปัจจุบัน; /help all ดูทุกโหมด; /help คำค้น ค้นชื่อหรือคำอธิบาย เช่น `/help resume` | หน้าจอหลัก (TUI), Classic (--classic), Legacy (--legacy) |
| `/model` | ดู provider, โมเดล และ API ที่ตั้งค่าไว้ (ไม่ได้เปลี่ยนโมเดล) | หน้าจอหลัก (TUI), Classic (--classic), Legacy (--legacy) |
| `/quit (หรือ /exit, :q)` | ออกจากโปรแกรม; Classic ขณะทำงานต้องสั่งซ้ำเพื่อยืนยัน | หน้าจอหลัก (TUI), Classic (--classic), Legacy (--legacy) |

### ควบคุมงาน

| คำสั่ง | ใช้ทำอะไร | โหมด |
|---|---|---|
| `/stop (หรือ /pause)` | ขอหยุดงาน AI; การกระทำที่เริ่มแล้วอาจต้องรอให้จบก่อน | หน้าจอหลัก (TUI), Classic (--classic), Legacy (--legacy) |
| `/continue` | ให้ AI ทำงานเดิมต่อ; อาจเรียกเครื่องมือและแก้ไฟล์ต่อ | หน้าจอหลัก (TUI), Classic (--classic), Legacy (--legacy) |
| `/status` | ดูจำนวนครั้งที่ทำต่อและสถานะการใช้งาน; Legacy แสดงสถานะ autonomous เพิ่มด้วย | หน้าจอหลัก (TUI), Classic (--classic), Legacy (--legacy) |
| `/budget` | ดูประมาณการ token และค่าใช้จ่าย ไม่ใช่ยอดเรียกเก็บจริงหรือเพดานบังคับ | หน้าจอหลัก (TUI), Classic (--classic), Legacy (--legacy) |
| `/queue` | ดูข้อความที่รอ AI ทำงานต่อ | หน้าจอหลัก (TUI), Classic (--classic) |

### บทสนทนา

| คำสั่ง | ใช้ทำอะไร | โหมด |
|---|---|---|
| `/sessions` | แสดงบทสนทนาที่บันทึกไว้ของโฟลเดอร์โปรเจคปัจจุบัน | หน้าจอหลัก (TUI), Legacy (--legacy) |
| `/resume ID` | กู้บทสนทนาเป็น session ใหม่โดยยังไม่รันงาน; ใช้ latest แทน ID ได้; /resume เปล่าแสดงรายการ เช่น `/resume latest` | หน้าจอหลัก (TUI), Legacy (--legacy) |
| `/clear` | เริ่มบทสนทนาใหม่; TUI/Legacy เก็บประวัติเดิมไว้ ส่วน Classic ล้างบริบทในหน่วยความจำ | หน้าจอหลัก (TUI), Classic (--classic), Legacy (--legacy) |
| `/copy` | คัดลอกข้อความทั้งหมดจากช่อง Output | หน้าจอหลัก (TUI) |
| `/compact` | ย่อประวัติเก่าด้วยข้อความตัดสั้น รายละเอียดบางส่วนอาจหาย (ไม่ใช่การสรุปครบถ้วน) | Legacy (--legacy) |

### ตรวจและกู้ไฟล์

| คำสั่ง | ใช้ทำอะไร | โหมด |
|---|---|---|
| `/checkpoint` | ดูรายการจุดบันทึกไฟล์ของ session ปัจจุบัน | Legacy (--legacy) |
| `/diff [step หรือ path]` | ดูความต่างของไฟล์กับ checkpoint; ไม่ใส่ค่าเพื่อดูภาพรวม เช่น `/diff 3` | Legacy (--legacy) |
| `/rollback [step]` | ย้อนการเปลี่ยนแปลงไฟล์ตาม checkpoint; เปลี่ยนไฟล์จริง ควรดู /diff ก่อน เช่น `/rollback 3` | Legacy (--legacy) |

### Sandbox และสิทธิ์

| คำสั่ง | ใช้ทำอะไร | โหมด |
|---|---|---|
| `/sandbox` | สลับโหมดทดลองแก้ไฟล์ โดยเก็บการเปลี่ยนแปลงรอ apply; ไม่รองรับทุกเครื่องมือ | Legacy (--legacy) |
| `/sandbox apply` | นำการเปลี่ยนแปลงที่พักไว้ไปเขียนไฟล์จริง | Legacy (--legacy) |
| `/sandbox discard` | ทิ้งการเปลี่ยนแปลงที่ยังไม่ได้ apply | Legacy (--legacy) |
| `/permissions` | ดูระดับสิทธิ์ที่ตั้งไว้ | Legacy (--legacy) |
| `/permissions set หมวด=ระดับ` | ตั้งสิทธิ์ auto / ask / deny; เปลี่ยนนโยบายการเรียกเครื่องมือ เช่น `/permissions set delete=ask` | Legacy (--legacy) |

## ปุ่มลัดหน้าจอหลัก

- `Esc`: ขอหยุดงาน
- `Ctrl+Q`: ออก
- `Ctrl+L`: เริ่มบทสนทนาใหม่
- ลากเลือกข้อความแล้ว `Ctrl+C` หรือ `Ctrl+Shift+C`: คัดลอกส่วนที่เลือก
- `Ctrl+Y`: คัดลอก Output ทั้งหมด
- `Ctrl+C` เมื่อไม่มีข้อความเลือก: ขอหยุดงาน หรือออกเมื่อว่าง

เครื่องมือที่ AI เรียก เช่น `read`, `write`, `shell`, `task_add` และเครื่องมือ Vault ไม่ใช่ slash command ให้พิมพ์คำสั่งภาษาปกติ เช่น “อ่านบันทึกโปรเจคแล้วสรุปงานที่ค้าง”

หลังอัปเดตโค้ด ต้องเปิด JudeCode ใหม่เพื่อใช้ help รุ่นนี้
